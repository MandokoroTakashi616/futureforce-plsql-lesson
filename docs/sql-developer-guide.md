# SQL Developer はじめてガイド

SQL Developer を一度も触ったことがない人向けに、インストールから PL/SQL を実行するところまでを順番に説明します。
このガイドが終わると、FutureForce の PL/SQLレッスンのハンズオンに取り組めるようになります。

## 先に読んでおくこと

- SQL Developer の画面は、パソコンの言語設定によって**日本語か英語**で表示されます。このガイドでは「日本語の表記（英語の表記）」の形で両方を書いています
- ボタンの名前が分からないときは、**マウスをボタンに重ねてしばらく待つ**と名前（とショートカットキー）が表示されます
- 画面の細かい見た目はバージョンによって変わることがあります。このガイドは 2026年9月時点の SQL Developer 26.2 を想定しています

## 全体の流れ

| 手順 | やること |
|---|---|
| 1 | SQL Developer をインストールする |
| 2 | 学習環境（Docker の Oracle）を起動する |
| 3 | 画面の見方を知る |
| 4 | 接続を作る |
| 5 | SQL を1文実行する |
| 6 | PL/SQL を実行して出力を見る |
| 7 | ファイルを開いて実行する（データのリセット） |
| 8 | 変更の確定・取り消しを知る |

---

## 1. SQL Developer をインストールする

1. [SQL Developer のダウンロードページ](https://www.oracle.com/database/sqldeveloper/technologies/download/) を開く
2. OS に合うファイルをダウンロードする。どちらも Java（JDK 17）が同梱されているので、Java を別に入れる必要はありません

   | OS | ダウンロードするファイル |
   |----|--------------------------|
   | Windows | ファイル名が `-x64.zip` で終わるもの（`-no-jre.zip` は Java 同梱なしなので選ばない） |
   | Mac（Apple Silicon） | ファイル名が `-macos-aarch64.app.zip` で終わるもの |

3. ダウンロードした zip を展開する
4. 起動する
   - Windows: 展開したフォルダの中の `sqldeveloper.exe` を実行する
   - Mac: 展開してできたアプリを「アプリケーション」フォルダに移して開く
5. 初回起動時に確認のダイアログが出た場合は、内容を読んで進めてください（以前の設定を引き継ぐか聞かれた場合は「いいえ」で問題ありません）

> Intel 版 Mac 向けのファイルは、ダウンロードページに掲載されていません。
> Windows で起動しない場合、ダウンロードページには `MSVCR100.dll` が必要という注意書きがあります。

## 2. 学習環境を起動する

SQL Developer は「データベースに接続して操作する道具」なので、接続先のデータベースが動いている必要があります。
ターミナル（Mac: ターミナル／Windows: Git Bash）で次を実行し、`STATUS` が `healthy` になるまで待ちます。

```bash
cd futureforce-plsql-lesson
docker compose up -d
docker compose ps
```

まだ clone していない場合は、リポジトリの [README](../README.md) の「セットアップ」から始めてください。

## 3. 画面の見方

SQL Developer の画面は、大きく次の3つに分かれています。

| 場所 | 名前 | 役割 |
|---|---|---|
| 左側 | 接続（Connections） | 作成した接続の一覧。ここから接続する |
| 右側の上 | ワークシート（Worksheet） | SQL や PL/SQL を書く場所 |
| 右側の下 | 結果のタブ | 実行結果が表示される。実行の仕方によってタブが変わる（手順5・6） |

左側に「接続」が見当たらない場合は、メニューの「表示（View）」→「接続（Connections）」で表示できます。

## 4. 接続を作る

「接続」は、**どのデータベースに、どのユーザーで入るか**を保存した設定です。一度作れば、次からはダブルクリックで接続できます。

1. 左側の「接続（Connections）」を**右クリック**し、「新規接続（New Connection）」を選ぶ
2. 開いたダイアログに、次の値を入力する

   | 項目 | 入力する値 | 補足 |
   |---|---|---|
   | 名前（Name） | `futureforce-plsql` | 自分で見分けるための名前。何でもよい |
   | ユーザー名（Username） | `learner` | |
   | パスワード（Password） | `learner` | |
   | パスワードの保存（Save Password） | チェックを入れる | 次から入力しなくて済む |
   | 接続タイプ（Connection Type） | 基本（Basic） | 最初からこの値になっていることが多い |
   | ホスト名（Hostname） | `localhost` | 自分のパソコンのこと |
   | ポート（Port） | `1521` | |
   | SID / サービス名（Service name） | **サービス名**を選んで `FREEPDB1` | **「SID」ではなく「サービス名」**を選ぶ。ここを間違える人がとても多い |

3. 「テスト（Test）」を押す。ダイアログの下の方にある「ステータス（Status）」に「成功（Success）」と出れば入力は正しいです。エラーが出たら、下の「困ったとき」を見てください
4. 「保存（Save）」を押す
5. 「接続（Connect）」を押す

接続すると、左側の一覧に `futureforce-plsql` が追加され、右側にワークシートが開きます。

**次回からの接続**: 左側の `futureforce-plsql` をダブルクリックする（または右クリック →「接続（Connect）」）。

**ワークシートを閉じてしまったとき**: 左側の `futureforce-plsql` を右クリック →「SQLワークシートを開く（Open SQL Worksheet）」。

## 5. SQL を1文実行する（文の実行）

ワークシートに次の SQL を入力します。

```sql
SELECT COUNT(*) FROM products;
```

1. 入力した文の**文字の上をクリック**して、カーソルをその行に置く
2. ワークシートの上にある「**文の実行（Run Statement）**」ボタンを押す（Windows のショートカットは `Ctrl + Enter`）

画面下の「**問合せ結果（Query Result / Results）**」タブに、表の形で `10` と表示されれば成功です。

> **ボタンを押しても画面が一瞬動くだけで何も出ない場合は、カーソルが文の上にありません。** 文の実行は「カーソルがある1文」だけを実行するため、カーソルが空行などにあると、実行する文がなく何も起きません。文の文字をクリックしてから、もう一度押してください。

- ワークシートに複数の文を書いていても、実行されるのはカーソル位置の文だけです
- 結果は表の形で出るので、SELECT の結果を見るのに向いています

## 6. PL/SQL を実行して出力を見る（スクリプトの実行）

ワークシートの中身を消して、次を入力します。

```sql
SET SERVEROUTPUT ON

BEGIN
  DBMS_OUTPUT.PUT_LINE('Hello, PL/SQL');
END;
/
```

ワークシートの上にある「**スクリプトの実行（Run Script）**」ボタンを押します（ショートカットは `F5`）。

画面下の「**スクリプト出力（Script Output）**」タブに `Hello, PL/SQL` と、処理が完了した旨のメッセージが表示されれば成功です。

- スクリプトの実行は、**ワークシートに書いた内容を上から順に全部**実行します
- `SET SERVEROUTPUT ON` は「`DBMS_OUTPUT` の出力を表示する」という指示です。スクリプトの実行のときに効きます
- 最後の `/` は「ここまでを1つの PL/SQL ブロックとして実行する」という合図です

### 2つの実行ボタンの使い分け

| | 文の実行（Run Statement） | スクリプトの実行（Run Script） |
|---|---|---|
| Windows のショートカット | `Ctrl + Enter` | `F5` |
| 実行する範囲 | **カーソルがある1文**（カーソルを文の上に置く必要がある） | ワークシート全体（カーソル位置は関係ない） |
| 結果が出るタブ | 問合せ結果（SELECT の結果を表の形で表示。PL/SQL ブロックでは表は出ない） | スクリプト出力（テキスト） |
| `SET SERVEROUTPUT ON` | 効かない | 効く |
| 向いている用途 | SELECT の結果を表で見る | **PL/SQL の実行（レッスンではこちら）** |

> **Mac の場合**: キーボードの設定によっては `fn` キーを押しながら `F5` を押す必要があります。ショートカットが効かないときは、ボタンを押すか、ボタンにマウスを重ねて表示されるショートカットを確認してください。

### 文の実行で PL/SQL の出力を見たいとき（DBMS出力パネル）

文の実行では `SET SERVEROUTPUT ON` が効かないため、`DBMS_OUTPUT` の結果が表示されません。その場合は専用のパネルを使います。

1. メニューの「表示（View）」→「DBMS出力（DBMS Output）」を選ぶ。画面下に「DBMS出力」パネルが開く
2. パネルにある「**+**」ボタン（新しいDBMS出力タブの追加 / Add New DBMS Output Tab）を押す
3. 接続を選ぶ画面で `futureforce-plsql` を選ぶ

これで、その接続で実行した `DBMS_OUTPUT` の結果がパネルに表示されます。

レッスンでは基本的に**スクリプトの実行（F5）**を使うので、このパネルは「出力が出ない」と困ったときに思い出せば十分です。

## 7. ファイルを開いて実行する（データのリセット）

レッスンの途中でデータを変えてしまったときは、学習環境に入っている `sql/99_reset.sql` で初期状態に戻せます。テーブルとデータに加えて、レッスンで作ったプロシージャ・ファンクション・パッケージ・トリガーも削除されます（自分で作った練習用のものも消えるので注意してください）。

1. メニューの「ファイル（File）」→「開く（Open）」を選ぶ
2. clone したフォルダの `futureforce-plsql-lesson/sql/99_reset.sql` を選ぶ。ファイルの中身がワークシートとして開く
3. 「スクリプトの実行（Run Script）」（`F5`）を押す
4. 接続を選ぶ画面が出たら、`futureforce-plsql` を選ぶ
5. 「スクリプト出力」に、テーブルの削除・作成とデータ投入のメッセージが並べば完了です

確認のため、ワークシートで `SELECT COUNT(*) FROM products;` を実行し、`10` になることを確かめてください。

> うまくいかない場合は、ターミナルから `docker compose exec oracle sqlplus learner/learner@//localhost/FREEPDB1 @/opt/plsql/sql/99_reset.sql` でも同じリセットができます（Windows の Git Bash では README の「Windows（Git Bash）での注意」を見てください）。

## 8. 変更の確定・取り消し（コミット／ロールバック）

`UPDATE`・`DELETE`・`INSERT` でデータを変えたとき、その変更はまだ「仮」の状態です。

- **コミット（Commit）**: 変更を確定する
- **ロールバック（Rollback）**: 変更を取り消して、確定前の状態に戻す

ワークシートの上に「コミット」「ロールバック」のボタンがあります。

- レッスンの問題や模範解答は、データを元に戻すためにブロックの最後で `ROLLBACK;` を実行しています。**自分で書くときも、最後に `ROLLBACK;` を書く**ようにしてください
- 間違えて変更してしまったときは、まず「ロールバック」ボタンを押します。コミットしてしまった後なら、手順7のリセットで初期状態に戻せます

## 9. 覚えておくと便利な設定

### 行番号を表示する

エラーメッセージの `line 3` のような行番号を確かめるのに便利です。

「ツール（Tools）」→「プリファレンス（Preferences）」→「コード・エディタ（Code Editor）」→「行ガター（Line Gutter）」で、「行番号の表示（Show Line Numbers）」にチェックを入れます。

> Mac では「ツール」メニューではなく、アプリ名のメニュー（SQL Developer）の中に設定（Preferences）がある場合があります。

## 困ったとき

### 接続の「テスト」でエラーになる

エラーメッセージの先頭の番号（`ORA-` から始まる番号）で原因を切り分けます。

| エラー番号 | メッセージの例 | 原因と対処 |
|---|---|---|
| `ORA-12505` | `SID FREEPDB1 is not registered with the listener` | **「SID」を選んだまま** `FREEPDB1` を入れています。「サービス名」を選び直してください |
| `ORA-12514` | `Service FREEPDB is not registered with the listener` | サービス名の綴りが違います。`FREEPDB1`（最後に数字の1）か確認してください |
| `ORA-01017` | `invalid credential or not authorized; logon denied` | ユーザー名かパスワードが違います。どちらも `learner` です |
| `ORA-17820` | `The network adapter could not establish the connection` | データベースに届いていません。学習環境が起動しているか（`docker compose ps` で `healthy` か）、ホスト名 `localhost`・ポート `1521` が正しいかを確認してください |

> `ORA-17820` は、コンテナを起動した直後（まだ `healthy` になる前）にも出ます。数分待ってからもう一度テストしてください。

### 「文の実行」を押しても、画面が一瞬動くだけで問合せ結果が出ない

カーソルが文の上にありません。実行したい文の文字をクリックしてカーソルを置いてから、もう一度「文の実行」を押してください（手順5）。

### PL/SQL を実行したのに何も表示されない

- 「文の実行（Ctrl + Enter）」で実行していませんか？ → 「スクリプトの実行（F5）」で実行し直す
- ワークシートの先頭に `SET SERVEROUTPUT ON` を書きましたか？
- ブロックの最後に `/` を書きましたか？
- 結果を「問合せ結果」タブで探していませんか？ → 「スクリプト出力」タブを見る

### 途中で止まらなくなった（無限ループなど）

ワークシートの上にある「取消（Cancel）」ボタンで、実行中の処理を止められます。止まらない場合は、左側の接続を右クリック →「切断（Disconnect）」してから、接続し直してください。
