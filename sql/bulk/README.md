# 大量データ（準備中）

後半ユニット（カーソル・BULK COLLECT・パフォーマンス）で使う大量データの生成スクリプトを置く場所です。

## ルール

- `02_seed.sql` の基本データ（商品10件・顧客5件・注文5件）は**変更・追加しない**。FutureForce の教材の期待出力がこの値に依存しているため
- 大量データは基本テーブルに混ぜず、`bulk_` で始まる別テーブルに入れる
- 乱数を使う場合は `DBMS_RANDOM.SEED` でシードを固定し、誰が実行しても同じデータになるようにする
- ファイル名は `10_xxx.sql` のように番号から始め、実行順が分かるようにする
